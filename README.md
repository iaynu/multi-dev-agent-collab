# multi-dev-agent-collab

개발 작업에서 여러 에이전트가 충돌 없이 협업하기 위한 작업 공간입니다.

## 협업 흐름

1. 작업을 작은 단위로 나누고 각 작업의 완료 조건을 먼저 적습니다.
2. 서로 독립적인 조사와 구현은 병렬로 진행하고, 같은 파일을 수정하는 작업은 한 담당자에게 모읍니다.
3. 통합 담당자가 변경 내용을 검토하고 관련 검증을 실행한 뒤 기본 브랜치에 반영합니다.
4. 결과를 공유할 때 변경 사항, 실행한 검증, 남은 제한을 함께 기록합니다.

현재 저장소에는 별도 애플리케이션이나 테스트 명령이 없습니다. 구체적인 개발 과제가 생기면 해당 프로젝트의 실행 및 검증 방법을 여기에 추가합니다.
